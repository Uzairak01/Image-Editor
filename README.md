# Image Editor

A small browser-based image editor using plain HTML, CSS, and JavaScript.

## Overview

This project is a lightweight image editor that runs entirely in the browser. It provides a simple UI for loading images from your computer and performing basic editing operations.

## Files

- `index.html` — app entry and UI
- `script.js` — main application logic
- `style.css` — core styles
- `theme.css` — optional theme styles

## Usage

1. Open `index.html` in your browser (double-click or use the browser "Open File" option).
2. Alternatively run a local dev server for best results, e.g.:

```bash
# using Python 3
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

3. Use the on-screen controls to load an image and apply edits.

## Development

- Edit UI in `index.html` and styles in `style.css` / `theme.css`.
- Add or modify behavior in `script.js`.
